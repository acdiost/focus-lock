# Focus Lock

跨平台番茄时钟桌面应用，目标平台为 `Windows` 和 `macOS`。工作阶段正常计时，休息阶段在所有显示器上创建全屏锁定层，展示今日重要事项、一言、喝水提醒和站立活动提醒。

## 当前实现

- `Tauri + Rust + 原生 Web UI`
- 工作时长/休息时长可配置并持久化
- 今日重要事项最多 3 条，按自然日自动清空
- 在线一言缓存 + 本地离线文案兜底
- 休息阶段多屏全覆盖锁定窗口
- 系统托盘：显示主窗口 / 退出
- 开机启动开关已预留并持久化，后续可接平台级自启动注册

## 运行

1. 安装依赖：`npm install`
2. 运行开发模式：`npm run dev`
3. 构建桌面应用：`npm run build`

说明：托盘能力通过 `tray` Cargo feature 显式开启，日常开发和构建请使用仓库内的 `npm` 脚本，而不是直接调用默认参数的 `tauri dev/build`。

## 限制说明

- 这是应用级锁定，不是系统级锁屏。
- macOS 下如果希望更强的置顶与焦点恢复，通常需要用户额外授予辅助功能权限。
- 多屏热插拔目前通过运行期轮询同步锁定窗口，而不是系统级事件订阅。
- 开机启动目前只保存设置，不会自动写入系统启动项。
